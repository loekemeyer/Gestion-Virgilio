🏷️ Etiquetas de góndola (EAN-13)

Genera las etiquetas de slot para el picking con lectora (idea 8243). Dos EAN-13 por artículo: TODO = 779558700+NNN (mercadería completa) · FALTA = 779558701+NNN (le falta algo → se completa en la tablet). NNN = parte numérica del código (943E→943). El verificador (mod-10) se calcula solo. Salida ZPL (^BE) para la Zebra.

CódigoSectorNNNEAN TODOEAN FALTA

Rojo = varios artículos comparten el mismo NNN (ej. 502/502T, 323/323E). El scan los resuelve por el contexto de la tanda (el que pide ese pedido); si una tanda pide los dos, hay que mirar. Ver docs/idea-picking-scanner-etiquetas.md.
